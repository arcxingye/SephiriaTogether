# Sephiria Together

多人联机扩展，提供房间人数设置、中途加入、断线重连、奖励补偿、敌人缩放及 IP/LAN 联机。

当前版本 **3.10.0**，针对游戏 **Sephiria 1.1.2** 构建。菜单支持简体中文、繁体中文、英语、韩语和日语。

详细步骤见 [INSTALL.md](INSTALL.md)。

## 功能与使用

- **人数设置**：默认 16，可设置 2～250 的上限；实际承载人数取决于电脑、网络和玩法本身的限制。
- **中途加入与重连**：房主允许开局后加入；重新连接的玩家使用本局对应存档槽位。
- **进度与补偿**：可放宽主线章节要求；补发错过的经验、资源与适用奖励，选择类奖励通过原版物件领取。
- **敌人难度**：按人数调节额外生命和数量。默认前 4 人保留游戏原有生命缩放，超过 4 人后每多 1 人追加 15%。
- **联机辅助**：玩家状态、转账、求救、可选的延迟回血、清场复活、友伤和商人保护。
- **存档管理**：手动备份与存档切换。基础反作弊默认关闭，只覆盖部分直接改钱和物品写入行为。

默认 **F8** 打开菜单。检测到受支持的主键冲突时，菜单会临时改用 **F9** 等备用键，实际按键见游戏提示和诊断页；保存的快捷键不会被覆盖。默认求救键为 **R**。

核心房主侧功能只需房主安装；需要本地菜单、转账、求救或 IP/LAN 功能的玩家也应安装。其他内容 Mod 的全员安装、版本和加载顺序要求仍然有效。

## 两种加载方式的区别

**BepInEx 版**在进程启动时加载，首次主菜单可用。

**原生工坊版**在进入存档后加载，冷启动后的首次主菜单不能响应 F8。IP 设置流程是：

1. 进入一次存档，在菜单里保存下次会话的模式和端口。
2. 点击“退出当前会话，回标题应用”，按原版退出/结算流程操作。
3. 在标题页确认“当前实际模式”已匹配，再进存档建房或加入。

无需为此重启整个游戏，也不会热切换正在运行的连接。若原版自身无法进入存档，原生工坊版无法提前介入，该启动需求需用 BepInEx 版。

默认 TCP 端口为 **7777**，局域网发现使用 UDP **7780**。直连可输入 `IP:端口`。

## 3.10.0 的重点更新

- 适配游戏 1.1.2 与工坊加载流程，修复世界地图重载绑定及 F8 初始化问题。
- 延长并重试联机版本握手，把“尚未确认”与真正的游戏/Mod 版本不一致分开提示。
- 同步已运行 Steam 传输实例的人数上限，修复工坊晚加载后房间仍停留在旧人数限制的问题。
- 提供独立的原生工坊构建；保留 BepInEx 构建。
- 网络设置区分当前连接与已保存配置，支持回标题后双向切换通信方式。
- 增加已知快捷键冲突避让、房间人数协调和特殊玩法保护。
- 工坊发布元数据包含中文默认介绍及英文介绍。

两种构建、补丁静态校验及针对性回归测试已通过。用户已确认 1.1.2 下部署的 3.10.0 原生工坊版菜单可以打开；此前 3.9.8 的单人双向通信切换也已有实测。本次双机握手、第六人加入和多 Mod 组合仍需游戏内验证。兼容技术范围见 [COMPATIBILITY.md](COMPATIBILITY.md)，加载设计见 [DESIGN.md](DESIGN.md)。

## 问题反馈

先检查游戏版本、Mod 启用状态与当前文件的审核状态，再进入存档尝试实际菜单键。GitHub Release 与 Steam 工坊审核是独立流程；旧版批准不会自动适用于新 DLL。

反馈请附游戏/Mod 版本、房主或客机、同时启用的 Mod，以及 `%USERPROFILE%/AppData/LocalLow/TEAMHORAY/Sephiria/Player.log` 中相关报错。

## 从源码构建

需要本机游戏程序集和 .NET SDK；原生工坊包的开发校验使用开发环境中的 Mono.Cecil，运行包不包含它。补丁回归运行于 .NET Framework 4.8。

```powershell
$env:SEPHIRIA_DIR = "你的 Sephiria 游戏目录"
.\scripts\build.ps1
.\scripts\build-workshop.ps1
.\scripts\package.ps1 -Version 3.10.0 -IncludeWorkshop
```
